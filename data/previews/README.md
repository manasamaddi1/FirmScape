# CSV previews

These files are **preview samples** (first 100–500 rows) of the full datasets used in the project.

- The **full CSVs** are in the parent `data/` folder and are gitignored (except `firmscape_integrated_quarterly_cleaned.csv` and `merged_companies_housing.csv`).
- These **preview** CSVs are small enough to commit so others can see the schema and sample rows without the full data.

Each `*_preview.csv` corresponds to a full `*.csv` in `data/` (same columns; fewer rows).
